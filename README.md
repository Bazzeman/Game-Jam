# Game-Jam
I am going to attempt to create a game within a week

Using branches release, development and testing, but not branches like hotfix/name or feature/name because on this project I work alone.

Ganre: rebirth
theme: simple warfare, capture the point

General idea: The payer steps into a cloning machine which clones the player multiple times. The player will be able to control each clone as if it is their own body. When the currently controlled clone dies, the player goes back in time right after the previous clone was made and the player gets cloned once more. Since we went back in time the player will see what happened in its previous iterations.

**Example**
On the first iteration, clone 1 defeats an incomming enemy but dies in the progress. A new clone is created after the previously controlled clone was defeated. Since clone 1 on the first iteration defeated the incomming enemy, clone 2 on the second iteration has free passage because the enemy was already defeated in iteration 1.
